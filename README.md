## The fortune

> The legacy code you curse was written by someone who, like you, was only trying to ship by Friday.

One original line, 98 characters — a tired senior engineer's smile: the legacy code you curse was written by someone under the same Friday pressure you know too well.

## How it works

`main.ts` reads the single fortune line from `fortune.txt` and writes it, unchanged, to `/output/entry.txt`. No network, no secrets, no dependencies — just Node.

```sh
node main.ts
cat /output/entry.txt
```
